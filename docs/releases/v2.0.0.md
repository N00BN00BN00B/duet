**Claude Code and Codex in one window** — start with either agent, switch mid-thread, and the other picks up where the first left off.

### Download
- **[Duet-mac-arm64.dmg](https://github.com/N00BN00BN00B/duet/releases/download/v2.0.0/Duet-mac-arm64.dmg)** — macOS 13+ on Apple Silicon (open it and drag Duet to Applications)
- `Duet-mac-arm64.zip` — the same app, zipped

Duet isn't notarized yet: after the first launch attempt, go to **System Settings → Privacy & Security → Open Anyway** (or run `xattr -dr com.apple.quarantine /Applications/Duet.app`). You need [Claude Code](https://claude.ai/code) and/or [Codex](https://github.com/openai/codex) installed; onboarding helps you sign in.

### What's new in 2.0
- **Make it yours** — 13 themes, light/dark picks, accent, density, text size, chat width, fonts and calm animated backgrounds that pause when idle.
- **Describe a look** — "dark gradient with a wave effect" in Customize or `/theme …` in any chat; Claude or Codex designs it (checked for readable contrast), Undo in one click.
- **Smooth effort and model sliders** — drag from Faster to Smarter; the recommended setting is marked.
- **`/` command menu** — every Duet command, the agent's own commands and your Codex skills; Codex `/review`, `/compact`, `/init` and Fast mode work natively.
- **Usage tab** — tokens, cost and activity per day, model and agent, plus both plans' limits.
- **Chat sync** — all your Claude Code and Codex chats in the sidebar with their real dates, loaded only when opened.
- **Personality** — presets for both agents, or import your Claude Code output style.
- **`duet` command line**, onboarding for new users, connect prompts, storage cleanup.
- **Cleaner work log** — approved commands fold into one summary line per step group.

### Fixes
- Codex code reviews now finish in Duet, and Stop works during a review.
- Theme design with Claude is ~5× faster.
- The `/` menu fits on the home screen.
- Switching agents after a model preview keeps the app stable; sliders follow dragging immediately and keyboard selection updates their labels.
- Extra permission grants stay visible in the work log.

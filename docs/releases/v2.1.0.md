# Duet 2.1 — provider models and routing

Use additional model providers with Claude Code and Codex, and choose named fallback routes in the model menu.

## New

- **Models & routing** in Settings, with an optional OpenCodex engine installed directly from Duet.
- **Provider models** discovered from your connected providers: Gemini, Grok, DeepSeek, Kimi, Qwen, OpenRouter, Ollama and other providers supported by OpenCodex.
- **Routes** with ordered fallback or weighted distribution, editable inside Duet.
- **Provider dashboard** inside Duet's browser panel for API keys, OAuth, accounts and provider settings.
- **Existing server connections**, including HTTPS servers with separate model and management credentials.
- **Encrypted connection keys**, excluded from backups; Codex keys use environment references rather than saved configuration values.
- Connection changes carry the current conversation into a fresh native session. Failed routed models do not silently fall back to native accounts.

## Set up

Open **Settings → Models & routing**, choose **Install engine**, then **Providers**. Connect your providers and refresh the model list. API access, subscriptions, local model installation and billing depend on the provider.
